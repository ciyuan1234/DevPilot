# DevPilot AI 产品需求文档 PRD V1.0

## 1. 项目名称和定位

> DevPilot AI —— 可扩展的 AI 软件工程平台

DevPilot AI 是一个面向软件工程生命周期的 AI 平台，为开发者提供项目管理、代码理解、AI 辅助开发等基础能力，并通过插件化 Agent 架构支持开发者扩展新的 AI 能力。

### 平台与 Agent 的边界

平台负责：
- 用户
- 项目
- 权限
- 文件
- AI 模型
- Agent 管理
- 插件管理
- 运行环境

Agent 负责：
- PR Review
- Debug
- 代码解释
- 测试生成
- 文档生成
- 其他软件工程任务

## 2. 背景与设计思路

当前 AI 编程产品主要围绕代码补全、代码生成和对话式开发展开。随着 AI Agent 技术的发展，开发者可以进一步将 AI 能力封装为具有独立任务能力的组件。

DevPilot AI 希望构建一个统一的软件工程 AI 平台，使开发者能够在同一平台中管理项目、接入不同模型，并扩展不同类型的 AI Agent。

## 3. 产品目标

### 短期目标

> 完成一个可运行的软件工程 AI 平台 MVP。

MVP 需要包含：
- 用户系统
- 项目管理
- 文件管理
- AI Gateway
- 一个基础 AI 能力
- 基础 Agent 接口

### 中期目标

- 支持多 Agent
- 支持多模型
- 提供 Agent 插件机制
- 接入 Git 仓库
- 支持云端部署

### 长期目标

- 构建 Agent 生态
- 提供 Agent Marketplace
- 支持本地部署
- 支持企业私有化部署
- 支持多 Agent 协作

## 4. 用户定位

### 主要用户

- 学生开发者
- 个人开发者
- 初级软件工程师

### 潜在用户

- 企业开发团队
- 对数据隐私敏感的企业
- AI Agent 开发者

C++ 可以作为第一阶段重点支持语言，但不是产品限制。

## 5. MVP 功能范围

第一版优先实现最小闭环：

1. 用户登录 / 注册
2. 创建项目
3. 上传文件
4. 选择 AI 能力
5. 通过 AI Gateway 调用模型
6. 返回分析结果

### 第一阶段基础 Agent

- Code Explain Agent

用户上传一个 .cpp 文件后，系统通过 Agent 进行代码分析，并返回结构化结果。

## 6. 非目标

第一版明确不做以下内容：
- 不训练自己的大模型
- 不实现复杂多 Agent
- 不实现 Agent Marketplace
- 不允许第三方 Agent 直接运行在主服务器
- 不追求大规模并发
- 不支持所有编程语言

## 7. 成功指标

- 支持用户注册与登录
- 支持项目创建与文件上传
- 支持调用 AI Agent 对代码进行分析
- 支持模型统一接入
- 支持后续扩展新的 Agent 能力
